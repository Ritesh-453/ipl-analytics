# IPL Analytics Dashboard

## What it does
- Analyzes IPL data from 2008 to 2024 (1,095 matches, 260K+ ball-by-ball records)
- Dashboard tabs for teams, batting, bowling and venues
- Pre-match winner predictor (Random Forest)
- Live in-match win probability (Gradient Boosting)
- SQL analysis on SQLite (6 queries)

## Tech used
- **Language:** Python
- **Data:** Pandas, NumPy, SQLite
- **Visualization:** Plotly
- **Dashboard:** Streamlit
- **ML:** Scikit-learn, Joblib
